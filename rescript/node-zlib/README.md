# @reventlessdev/rescript-node-zlib

> ⚠️ **Alpha.** APIs and on-disk formats can change without notice between releases.
> Pin exact versions and expect breaking changes.

ReScript bindings for [node zlib](https://nodejs.org/docs/latest-v16.x/api/zlib.html).

## Install

```bash
pnpm add @reventlessdev/rescript-node-zlib
```

Add it to your `rescript.json` dependencies:

```json
{
  "dependencies": ["@reventlessdev/rescript-node-zlib"]
}
```
