# @reventlessdev/rescript-pulumi-pulumi

> ⚠️ **Alpha.** APIs can change without notice between releases.
> Pin exact versions and expect breaking changes.

ReScript bindings for [@pulumi/pulumi](https://github.com/pulumi/pulumi/tree/master/sdk/nodejs) - the Pulumi Node.js SDK.
Also see [official documentation](https://www.pulumi.com/docs/reference/pkg/nodejs/pulumi/pulumi/).

## Install

```bash
pnpm add @reventlessdev/rescript-pulumi-pulumi
```

Add it to your `rescript.json` dependencies:

```json
{
  "dependencies": ["@reventlessdev/rescript-pulumi-pulumi"]
}
```
