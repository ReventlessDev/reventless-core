# `aws-lambda-layer` (WIP)

This tool takes a module specification (e.g. `@reventless/reventless-aws@latest`) and bundles this module with all it's dependencies into a zip file. This zip file can be then used to create an aws lambda layer.

**NOTE: This is currently work in progress and may not be finished or contain bugs!**

## Usage

```
node index.js
```
