# `rescript-pulumi-pulumi`

ReasonML / Bucklescript bindings for [@pulumi/pulumi](https://github.com/pulumi/pulumi/tree/master/sdk/nodejs) - the Pulumi Node.js SDK.
Also see [official documentation](https://www.pulumi.com/docs/reference/pkg/nodejs/pulumi/pulumi/).

## Usage
- Add `rescript-pulumi-pulumi` to your dependencies in `package.json`.
- Add `rescript-pulumi-pulumi` to your dependencies in `bsconfig.json`.
- For general information see this monorepo's [readme](../../README.md)
