# `rescript-node-streams`

ReasonML / Bucklescript bindings for [node streams](https://nodejs.org/docs/latest-v12.x/api/stream.html).

## Usage
- Add `rescript-node-streams` to your dependencies in `package.json`.
- Add `rescript-node-streams` to your dependencies in `bsconfig.json`.
- For general information see this monorepo's [readme](../../README.md)
