# rescript-uuid

ReasonML / Bucklescript bindings for [uuid](https://github.com/uuidjs/uuid).

## Usage
- Add `@reventless/rescript-uuid` to your dependencies in `package.json`.
- Add `@reventless/rescript-uuid` to your dependencies in `bsconfig.json`.
- Add `uuid` to your dependencies in `package.json`
- For general information see this monorepo's [readme](../../README.md)

## Example
```re
let id = Uuid.v4(); // generate a new pseudo random based (v4) uuid
```
