# `rescript-node-zlib`

ReScript bindings for [node zlib](https://nodejs.org/docs/latest-v16.x/api/zlib.html).

## Usage
- Add `rescript-node-zlib` to your dependencies in `package.json`.
- Add `rescript-node-zlib` to your dependencies in `rescript.json`.
- For general information see this monorepo's [readme](../../README.md)
