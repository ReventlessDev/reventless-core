# `rescript-fast-csv`

ReasonML / Bucklescript bindings for [fast-csv](https://github.com/C2FO/fast-csv).

## Usage
- Add `rescript-fast-csv` to your dependencies in `package.json`.
- Add `rescript-fast-csv` to your dependencies in `bsconfig.json`.
